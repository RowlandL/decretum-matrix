# Contributing

Contributions must include clear provenance for code, documentation, fixtures,
and generated material. Do not submit content that you do not have the right to
license or distribute.

Unless explicitly marked otherwise in writing, contributions accepted into
this project are provided under Apache-2.0, including its copyright and patent
terms. Each commit must include a Developer Certificate of Origin line:

```text
Signed-off-by: Name <email@example.invalid>
```

Before submitting a change:

1. Add focused RED → GREEN tests for behavior changes.
2. Run the relevant source, privacy, legal, manifest, and package gates.
3. Record third-party provenance and preserve required license notices.
4. Do not commit credentials, private Shiguan bodies, host logs, local memory
   decisions, user paths, generated runtime state, or nested release archives.
5. Keep historical version tags and release artifacts immutable.

Maintainers may reject changes whose provenance, rights, safety, or release
evidence cannot be verified.
