- MCP 与 CLI 共用 public/domain API，工具集合由当前 manifest 确认，不回退早期五工具描述。
- 太子受旨、中书拟旨／问题拆解、尚书差遣拆解是不同职责，保留 1.0.9 澄清。
- 谱系采用版本化 `classified/review + reason`，历史合法谱系与编号保留。
- 四态断言属于召回改进；默认线性融合与可选 RRF 不因历史图示改写。
- 复用现有状态、胶囊、准入、receipt、journal；架构图新箭头不直接增加 dispatch 允许边或第二账本。
