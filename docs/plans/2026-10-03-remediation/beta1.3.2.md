## 1. 版本目标

多进程安装互斥；**中断安装可检测、可恢复或明确需人工处理**（补齐 CHANGELOG 明示的未实现边界：断电恢复与并发安装串行化）。复用既有 CAS/锁/前像机制，不新建事务框架。

## 2. 工作包

1. **跨进程互斥**：复用既有锁机制；超时检测与僵尸锁处理（与 1.2.3 的 F12 修复衔接）。
2. **安装检查点与恢复路径**：中断检测 + 恢复/回滚命令（走既有 CLI 注册，不新增平行入口）。
3. **并发与中断验证**：多进程并发安装对照；强制中断 + 恢复验证。

## 3. 验收（可测）

- [ ] N 并发安装只有一个完整成功，其余明确拒绝或等待，无互相破坏（隔离 HOME）；
- [ ] 强制中断后：恢复成功或 `RECOVERY_REQUIRED`（不伪称成功）；
- [ ] 与 F02/F12 修复联合回归（锁范围 + 锁释放 + 检查点）；
- [ ] 未新建事务框架、未新增哈希校验脚本。

## 4. 证据

- 并发对照记录（进程/退出码/投影结果）；
- 中断-恢复对照（含失败样本保留）；
- CLI 恢复命令的输出样例。

## 5. 边界

- 断电模拟以强制中断近似，需在文档中注明"近似验证"；
- 不改变安装策略与投影集合；不触用户现用安装（隔离 HOME）。
