## 1. 版本目标

评估治理控制台与插件扩展的可行性，给出**进入实现的门槛**（能力、权限、风险、工作量）；结论可为"原型计划"或明确"不做"。

## 2. 工作包

1. **Web UI 评估**：只读优先、基于既有服务能力、本地运行；列出必要权限与风险（含与史馆私密边界的交互）。
2. **插件接口评估**：扩展点、加载机制、与既有 governance 清单（`governance-implementations.v1.json`）的关系；第三方扩展的安全边界。
3. **结论**：原型计划（含最小只读范围）或"不做"的理由；如做原型，给出版本归属建议。

## 3. 验收（可测）

- [ ] 评估文档：能力、权限、风险、工作量、门槛条件；
- [ ] （可选）只读原型截图/演示（若评估支持且成本可控）；
- [ ] 明确结论与下一步建议；
- [ ] 未引入公网暴露、未自动安装、未建第二套状态/身份框架。

## 4. 证据

- 评估文档；
- （如原型）运行记录与截图；
- 权限/风险清单。

## 5. 边界

- 不建第二套状态/身份框架；不公网暴露；不自动安装；
- 与既有 Web 服务（`serve_shiguan_tree` 等）的关系须说明（扩展而非平行重建）。
