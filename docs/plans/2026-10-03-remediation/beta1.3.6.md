## 1. 版本目标

以一个**纯协议 / 只读模块**做等价试点，量化"减少 Python 依赖"的真实收益。只加 SDK/CLI 包装不算脱 Python——试点必须给出可度量证据。

## 2. 工作包

1. **选点**：纯协议 / 只读 API（如只读 MCP 工具或只读 CLI 命令），不触碰状态写入。
2. **等价实现 + 契约测试**：相同 schema、错误语义、scope、ID、路径与记录（逐字段对照）。
3. **量化**：启动时间、无 Python 环境可用性、体积、维护成本（与现路径对比）。
4. **结论**：是否值得扩大（写入 / 状态下沉另评）。

## 3. 验收（可测）

- [ ] 等价测试通过（逐字段对照表，含错误路径）；
- [ ] 度量报告（启动/体积/依赖需求，与现路径同条件对比）；
- [ ] 结论与后续建议（扩大 / 缩小 / 停止）。

## 4. 证据

- 对照表（字段级）；
- 度量原始数据与测量脚本；
- 结论文档。

## 5. 边界

- 不改状态写入 / 安装 / 恢复；不引入第二套协议或身份；
- Laya 训练保留独立 Python；模型服务先复用既有 HTTP seam。新增原生推理仅按本页 2026-11-01 增补做有界等价试点，未验证则保留现有后端；
- 若选点为只读 MCP 工具，须与 1.2.2/1.2.8 的公共面修复保持一致（不得复刻旧行为）。

## 2026-11-01 计划增补 · Rust/Node网关与原生模块等价试点

状态：**PLANNED_UNVERIFIED**。本次仅修订计划；新增项的实施与晋级按本版出口，不将历史发布条款当作本次发布授权。

1. 自管模型API场景优先验证TensorZero现有Rust网关，Node负责最小宿主/CLI/MCP适配；不叠加多个网关。
2. 按剖析迁移只读过滤/排序/协议热点，shadow、契约等价后可回滚切换；不借只读试点迁移写权。

4. Laya训练先保留Python；原生推理仅做单列的兼容/精度试点，tokenizer/决策头/算子未验证则继续既有服务。
