## 1. 版本目标

superCC 外部依赖（zellij + squad）有**明确清单、检查命令与文档**；"非标准环境"判定可复现，并给出可照做的安装指引。**不承诺自动安装**（如需自动安装，另立评估）。

## 2. 工作包

1. **依赖清单**：zellij、squad 的版本要求、安装方法、平台差异（Windows/WSL）。
2. **环境验收命令**：复用既有检查机制，输出"标准 / 非标准"判定与缺失项（历史收据 2026-07-21 / beta1.0.2 中为 `NOT_STANDARD_ENVIRONMENT`；需在当前版本重新判定并可复现）。
3. **文档**：superCC 环境搭建与验证路径（接既有 wiki/references，不新建平行材料）。
4. 明确"不自动安装"的边界，并在文档中给出人工步骤。

## 3. 验收（可测）

- [ ] 无 zellij/squad 环境 → 判定"非标准环境"并列出缺失项 + 安装指引（附照做记录）；
- [ ] 有环境 → 验收命令通过，判定可复现（同一环境两次运行一致）；
- [ ] 依赖清单与文档步骤逐条对应；
- [ ] 未引入自动安装或包管理器副作用。

## 4. 证据

- 两种环境的命令回执对照；
- 文档照做记录；
- 判定输出样例（JSON/文本）。

## 5. 边界

- 不做自动安装；不改 superCC runtime 语义；不宣称"标准环境已达成"（除非真实验收）；
- Windows 上如需 WSL，文档须明确前提，不默认可用。

## 6. 文档任务

- `CHANGELOG.md`：beta1.3.1 条目；
- 执行记录与总纲。

## 2026-11-01 计划增补 · 统一入口与广泛语义分配试点

1. 采用统一逻辑入口、规则快路、可替换决策provider及宿主执行器；取消/心跳/流式片段不等待语义模型。
