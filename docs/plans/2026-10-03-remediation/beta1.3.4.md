## 1. 版本目标

用户文档达到"可照做"程度：quickstart、Troubleshooting、典型场景示例按**具体内容改进**，不新建平行材料（Wiki 已有 Troubleshooting / Usage / CONTRIBUTING）。

## 2. 工作包

1. **quickstart**：5 分钟首装 + 首个任务（与 F21 修复后的安装路径一致）。
2. **Troubleshooting 扩充**：按症状（安装失败 / CLI 慢 / 日志过大 / 派遣卡住）给命令级指引。
3. **典型场景示例**：3–5 个（多仓库治理、官署配置、记忆检索等）。
4. **英文文档**：**需另行授权**（不在本次授权内，本版不实施）。

## 3. 验收（可测）

- [ ] 文档步骤照做可复现（附照做记录）；
- [ ] 与当前命令面一致（逐参数核对，无过期参数）；
- [ ] 不新建与现有 wiki 重复的平行页面（检查页面清单差异）；
- [ ] 英文文档未被擅自加入（或已获授权并单独记录）。

## 4. 证据

- 各文档的照做记录（命令 + 输出）；
- 页面清单前后对照（证明无平行材料重复建设）。

## 5. 边界

- 不重写 README 主体；英文文档待授权；
- 文档内容以当前实现为准，不描述未实现的未来能力（除标注"计划中"）。

## 6. 文档任务

- 本版即文档交付版本：quickstart、Troubleshooting 补充、场景示例；
- `CHANGELOG.md`：beta1.3.4 条目；
- 执行记录与总纲。
