## 审查结论与已实施修复

### P1：安装末段失败可能留下新投影与未完成绑定

原 `install_current_agent_copy` 已应用文件投影后，绑定/回执写入异常不在完整补偿范围内：普通 I/O 异常可逃逸，绑定契约失败也可能直接返回而未还原投影。

修复将绑定构建、前像保存、绑定持久化及安装回执持久化纳入同一异常处理边界。复用既有备份恢复与绑定前像恢复能力，两项恢复独立尝试；只有两者成功才返回 `ROLLED_BACK`，否则保留恢复材料并返回 `RECOVERY_REQUIRED`。安装回执改用既有原子 JSON 写入函数。

边界：解决本进程可捕获的失败；不宣称解决断电、强制结束进程、磁盘永久损坏或多个安装器并发竞争。

### P1：候选 npm 包遗漏 installer-only 载荷，源码安装器掩盖缺失

本地候选契约未继承基础契约的安装专用文件列表；烟测又从源码目录调用安装器，因此测试通过不足以证明候选包能够独立安装。

修复继承 `installerFiles`，直接调用候选包内 `bin/install-runtime.py`，不再传入源码根兜底。增加缺少安装专用载荷必须拒绝的负例，并检查实际调用记录。运行文件规范化与安装专用文件原始字节处理保持各自契约。

### P2：精简 Python 环境误判合法技能元数据

不安装 PyYAML 时，旧后备解析器忽略缩进，把 `metadata.author/version` 当成非法顶层字段；Windows 上通过 `python -S -B scripts/quick_validate.py .` 实际复现。

修复实现有明确边界的标量与 metadata 映射子集，拒绝重复键、错误缩进、空描述和不支持的复杂语法，并提示复杂 YAML 需要 PyYAML；不将它宣传为完整 YAML 实现。补齐 Agent Skills 规范的 compatibility 与 metadata 类型检查，无新增依赖。

### P2：跨平台隐私回归夹具污染全局平台状态

旧 Windows 模拟通过共享 `os` 模块修改全局 `os.name`，使 Linux 上的 pathlib 误选 WindowsPath；另有 POSIX 符号链接被当目录删除。修复只隔离测试后端的模拟对象，并采用相应链接清理方式，不删除负例、不降低生产安全条件。

真实 Windows 包内入口测试另外发现烟测环境继承外层 CODEX_HOME，导致安装后验收读取错误的测试配置；该失败真实触发完整回滚。隔离进程环境现在将 CODEX_HOME 固定在本次临时 home 的 .codex，下游安装与公开 CLI 使用同一隔离环境，并新增外层变量污染负例。未读取用户现用配置。
