# Decretum Matrix（诏令矩阵）

Decretum Matrix（诏令矩阵）是一个本地 skill 路由与可验证协作内核。它把任务分配给
太子、三省、尚书省、六部和有界工坊，并把权限、证据、隐私与收口门禁绑定到同一任务语义。

当前源码与发布目标：`beta1.1.2`（npm `1.1.2-beta.0`，`beta` dist-tag）。远端
Latest、package 与 Wiki 状态只以发布后的远端回读为准。

## 最短路径

```sh
npm install @rowlandl/decretum-matrix@beta --registry=https://npm.pkg.github.com
```

```text
$decretum-matrix
```
